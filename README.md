# Cycloid — тестовая отрисовка циклоидального редуктора

Программа на Python для расчёта и отрисовки циклоидального редуктора (звёздочка-диск,
ролики корпуса, выходные пальцы, эксцентрик) с выгрузкой деталей в SOLIDWORKS.

## Запуск

```
python cycloid.py
```

Нужен Python 3 с `tkinter` (входит в стандартную поставку). Для выгрузки в SOLIDWORKS
дополнительно:

```
pip install pywin32
```

и установленный SOLIDWORKS на этом же компьютере (проверялось на SOLIDWORKS Design 2026).

## Файлы

| Файл | Назначение |
|---|---|
| `cycloid.py` | расчёт профиля диска и окно с отрисовкой |
| `sw_export.py` | выгрузка деталей в SOLIDWORKS через COM API |
| `sw_out/` | сюда сохраняются детали `.SLDPRT` (создаётся сама, в git не попадает) |

## Геометрия

Профиль диска — эквидистанта к укороченной эпициклоиде на радиус ролика:

```
x = R*cos t - rp*cos(t+psi) - e*cos(N t)
y = -R*sin t + rp*sin(t+psi) + e*sin(N t)
psi = atan( sin((1-N) t) / (R/(e N) - cos((1-N) t)) )
```

- `N` — число роликов корпуса, `R` — радиус окружности роликов, `rp` — радиус ролика,
  `e` — эксцентриситет.
- Зубцов диска `N-1`, передаточное число `N-1` (26:1 при N=27).
- Дисков 1 или 2; второй диск сдвинут на 180° по эксцентрику.
- Выходное звено поворачивается на `-phi/(N-1)`.

## Окно

- **Параметры:** у каждого есть ползунок, поле для ввода числа и галочка «фикс».
  Зафиксированное значение программа не меняет, под него подстраиваются остальные.
- **Согласование размеров:** детали не должны налезать друг на друга. Зафиксированные `rp` и `e`
  имеют приоритет: при уменьшении `R` (или росте `N`) программа поднимает `R`, а если он тоже
  зафиксирован — уменьшает `N`. Если подогнать нечего, внизу появляется предупреждение «!».
- **Авто-размеры:** `Rh` (радиус окружности пальцев), `ro` (диаметр пальца) и диаметр центрального
  отверстия считаются от `R`, `rp`, `e`. Ввод любого из них вручную сразу фиксирует его.
- **Галочки:** ролики, диск, заливка, выходные пальцы, ступица, корпус, эксцентрик/орбита,
  делительные окружности, контрольный профиль в фазе 0.
- **Анимация:** кнопка «Старт анимации», скорость в °/кадр, угол вала задаётся вручную.
- **Пресет 26:1:** N=27, R=70, диаметр ролика 12, e=1.5, два диска, 6 пальцев.
- Окно открывается развёрнутым на весь экран.

В строке «Мин. зазор диск-ролик» показывается расчётный зазор: около 0 означает касание,
отрицательное значение — врезание.

## Выгрузка

**DXF** — кнопка «Экспорт DXF»: профиль диска в фазе 0 ломаной, отверстия под пальцы
и центральное отверстие.

**SOLIDWORKS** — панель «Выгрузка в SolidWorks»: «Звёздочка», «Корпус», «Эксцентрик», «Ролик»,
«Все детали». Файлы сохраняются в `sw_out/`.

| Деталь | Что строится |
|---|---|
| Звёздочка | сплайн профиля, отверстия под пальцы (радиус `ro+e`), центральное отверстие; толщина — ползунок «Толщина диска» |
| Корпус | круг радиусом `1.3*R` с канавками под ролики (по радиусу ролика, без зазора) |
| Эксцентрик | вал с центральным отверстием и шейками под диски, смещёнными на `e` в противоположные стороны |
| Ролик | цилиндр радиусом `rp` |

Размеры производные от толщины диска `T`: шаг дисков `T+1` мм, толщина корпуса и длина роликов
`число_дисков*(T+1)+2` мм. Эксцентрик: радиус шейки = радиус отверстия диска, радиус вала = он
минус `e`, радиус отверстия в валу — половина радиуса вала, по 10 мм шейки на концах.

Не выгружаются: выходная ступица и пальцы, подшипники, шпоночные пазы, крепёжные отверстия
корпуса. Сборка не создаётся: фазу эксцентрика и дисков относительно канавок корпуса нужно
задать при сборке.

## Ограничения

- Размеры в мм; SOLIDWORKS API получает метры, пересчёт выполняется в `sw_export.py`.
- При первом запуске SOLIDWORKS окно программы может «зависнуть» на время его старта.
- Расчётные размеры автоматического режима — прикидка, окончательные размеры нужно проверять
  в CAD.
